# 南あわじ防災アクションラボ

ワークショップの記録を検索し、避難所での課題について考えるための日本語ブラウザ試作です。トップページは福良地区公民館のデータを中心に構成しています。

## 起動方法

1. このフォルダー内の `index.html` をブラウザで開きます。
2. 画面上部のタブで「アイデア図鑑」「場面から考える」「データを見る」を切り替えます。

ローカルで直接開けない場合は、このフォルダーを静的ファイル用のWebサーバーで配信してください。インターネット接続がある場合、見出しの書体にGoogle Fontsを読み込みます。接続できない環境では端末の標準ゴシック体に切り替わります。

## 元データと採用シート

添付Excel「奥村ゼミ 専門演習発表会用データ 南あわじ市ワークショップ.xlsx」と、会話添付の「南あわじ市ワークショップ データの見方」資料を確認しました。原シートを各会場1枚ずつ採用しています。

| 会場 | 採用シート | 文言のある記録行 | 色の意味（資料に基づく） |
| --- | --- | ---: | --- |
| 福良地区公民館 | 福良地区公民館 | 273 | 青：個人ができる対策、黄：地域での役割・職能でできる対策 |
| 福良小学校 | 福良小学校 | 204 | 黄：困りごと、赤：対策、青：将来の職業や福良の地域の仕事から考えたこと |
| 三原高校 | 三原高校 | 85 | 赤：困りごと、黄：高校生としてできる対策 |

各シートの文言欄が空の行は除外しています。したがってアプリの記録行の合計は562件です。文言の重複は削除せず、元の行のまま残しています。シート名に「タブあり」とある2枚は、原シートの記録と文言・色の組み合わせが一致する代替配置のため、二重計上を避けて採用していません。代替シートからのみ得られる追加データがあるとは確認できませんでした。

## 項目の読み替え

- 文言はExcelの記録をそのまま表示します。班や付箋を書いた人の氏名は表示しません。参加者名簿はアプリに含めていません。
- 福良公民館では「グループ番号」を班として表示し、「フローチャートの項目番号」を項目として表示します。数字の全角・半角だけを読みやすさのために揃えています。
- 福良公民館の項目「0」は図中の対策項目とみなさず「未割当（0）」として表示します。空欄は別に「未記入」とします。
- 小学校と高校には「グループ番号」欄がないため、班別分析は表示しません。原シートの第3列をフローチャート項目として扱います。
- フローチャート項目欄に複数番号がカンマや空白で区切られている場合、ダッシュボードでは番号ごとに数えます。そのため、項目の計数合計は文言の記録行数を超えることがあります。疑問符などを含む曖昧な文字列は「要確認」として残します。空欄と「0」は番号とは区別します。
- 色の意味は会場別に表示します。同じ色でも会場間で意味を揃えた比較はしません。
- ダッシュボードは記録行の数と分布を示します。ゼロや空欄を、実際の活動がなかったことと解釈することはできません。

## 場面から考える機能

4つの場面は、記録の中の具体的な語を探すための入口です。各場面に設定した語が福良公民館の文言に含まれている記録を表示します。語の選定と場面の見出しは試作上の編集判断であり、妥当性検証済みの分類ではありません。表示された意見は実際の記録ですが、その意見が実行されたか、災害関連死を減らす効果があるかは、このデータから判断できません。効果点数や実施機関へのリンクは設けていません。

## 制約と次の確認事項

- 小学校・高校のデータ説明はワークショップ説明資料に基づきます。欄名・番号の一部が曖昧な記録や、空白の付箋色は修正・推測していません。
- 原Excelには、同じ意見の繰り返し、複数の項目番号、記入漏れがあります。文言は一切統合していません。
- 元データのシートにあるフローチャート画像や、項目番号と問題文の対照表はこの試作に含めていません。項目番号そのものから課題内容を推測しないでください。
- 公開前に、記録文の再識別リスクや個人・団体を特定しうる記載を研究担当者が再点検してください。現状、参加者名簿や氏名欄はアプリに含めず、記録文は原文保持を優先しています。
- 次段階では、研究担当者が項目番号の対応表を確認し、検索語とシナリオの分類を参加者・研究者と検証したうえで、必要に応じて匿名化の基準や分析計画を明記してください。
